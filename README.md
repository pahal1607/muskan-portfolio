# Muskan Pandit — Interior Design Portfolio

A responsive, mobile-first editorial portfolio in deep burgundy, warm ivory and champagne accents. This is a static website and needs no build step.

## Preview locally
1. Extract this ZIP.
2. Keep `index.html` and the `assets/` folder together.
3. Open `index.html` in Chrome, Edge or Safari. Internet access is needed for Google Fonts; project imagery is included locally.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `muskan-portfolio`.
2. Extract this ZIP on your computer.
3. Upload the **contents** of this folder to the repository root: `index.html`, `assets/`, `README.md`, `.nojekyll` and `.gitignore`. Do not upload only the ZIP.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for publishing; the public URL appears in Settings → Pages.

## Included
- Mobile-first responsive homepage with oversized animated portfolio typography and centred portrait.
- Floating cropped project-image cards, orbit rings, sparkles, intro loader, scroll reveals and motion effects.
- Project categories, detail views, about/profile, skills/services and contact sections.
- Admin dashboard prototype for adding/removing projects.
- Local project imagery extracted from the supplied portfolio PDF.

## Admin prototype — important
Demo credentials: `studio` / `muskan2026`.

The dashboard is **not secure production authentication**. Changes are stored only in the current browser and do not sync to other devices or visitors. For a live website where Muskan can securely manage projects from her phone, connect secure authentication, a database and cloud image storage (e.g. Supabase or Firebase).

The contact form currently opens the visitor’s email app (`mailto:`). Verify contact details and connect a real form backend before launch.
