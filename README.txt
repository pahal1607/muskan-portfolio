MUSKAN PANDIT — EDITORIAL BURGUNDY PORTFOLIO — HOME V2

HOW TO VIEW
1. Extract the ZIP folder.
2. Keep index.html and the assets folder together.
3. Open index.html in Chrome or Edge. An internet connection helps load the fonts.

DESIGN
New mobile-first editorial composition inspired by the supplied references: portrait centred in front of oversized PORTFOLIO typography, deep burgundy/wine palette, cropped/asymmetrical project imagery, ivory editorial sections, champagne details, motion and scroll reveals, responsive project gallery and image detail modal.

SOURCE MATERIAL
Project visuals are taken from Muskan Interior Portfolio.pdf. Profile, skills, education/project context and contact details are taken from the provided portfolio material. Some project imagery uses faithful page renders from the PDF to preserve the supplied work as presented.
